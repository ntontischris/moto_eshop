## Γρήγορα facts (cheat sheet)
- **Ίδρυση:** 1982, Θεσσαλονίκη · **4η δεκαετία** · ΓΕΜΗ **058969304000** · ISO 9001
- **Εγκαταστάσεις:** ~6.000 τ.μ., κεντρικά Βι.Πε. Σίνδου
- **Own brands:** Pilot (κράνη), Nordcode (ένδυση), Fovos (off-road) — τρίπτυχο **ασφάλεια–design–τιμή**
- **Αποστολή:** δωρεάν >50€ (αλλιώς 2€), σε 24h · **Επιστροφές:** 14 ημέρες · **Εγγύηση:** 2 έτη
- **Πληρωμές (τρέχον):** Viva (cards/IRIS/Apple/Google Pay/Klarna) + PayPal + κατάθεση + αντικαταβολή · **ΦΠΑ 24%**
